# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior data to uncover spending patterns, customer segments, product preferences, and subscription trends.

The analysis was performed using Python, SQL Server, and Power BI to transform raw transaction data into business insights and interactive dashboards.

---

## Tools & Technologies Used

- Python (Pandas, NumPy)
- SQL Server
- Power BI
- Excel
- Jupyter Notebook

---

## Dataset Information

- Total Transactions: 3,900
- Features: 18
- Average Purchase Value: $59.76
- Average Customer Rating: 3.75

Dataset includes:
- Customer demographics
- Purchase details
- Product categories
- Shipping methods
- Discounts
- Subscription status

---

## Project Workflow

### 1. Data Preparation in Python
- Loaded and explored dataset using Pandas
- Checked missing values and data types
- Performed data cleaning and preprocessing
- Filled missing review ratings using category median
- Created new features:
  - age_group
  - purchase_frequency_days

---

### 2. SQL Analysis
Performed SQL queries to analyze:
- Revenue trends
- Customer segmentation
- Product performance
- Subscription behavior
- Discount impact
- Repeat customer analysis

---

### 3. Power BI Dashboard
Created an interactive dashboard with:
- Revenue analysis
- Sales by category
- Customer segmentation
- Subscription insights
- Product performance
- Interactive filters and slicers

---

## Key Insights

### Revenue Insights
- Male customers generated nearly 2x more revenue than female customers
- Middle-aged customers contributed the highest revenue
- Young adults contributed the lowest revenue

### Customer Segmentation
- Loyal customers formed the majority of the customer base
- Returning customers showed strong repeat purchase behavior
- New customers represented future growth opportunities

### Subscription Analysis
- 27% customers had subscriptions
- 73% customers were non-subscribers
- Average spending remained similar between subscribers and non-subscribers

### Product Insights
Top-rated products:
- Gloves
- Sandals
- Boots
- Hats

Best-selling categories:
- Clothing
- Accessories
- Outerwear
- Footwear

---

## Business Recommendations

- Improve subscription conversion campaigns
- Introduce loyalty reward programs
- Optimize discount strategies
- Focus marketing on high-revenue customer segments
- Promote top-rated products in campaigns
